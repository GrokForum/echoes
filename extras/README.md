# Extras: the runner-ups

Before ECHOES was built, three tiny-game concepts were written up and compared ([full comparison](../docs/concepts.md)).

| Concept | One-liner | Why it lost |
|---|---|---|
| [SONAR](SONAR.md) | Find the exit of a pitch-black maze; every ping lights it up for a moment. | Core idea is close to Dark Echo. |
| [DRIFT](DRIFT.md) | Tetris with one key: pieces swing like a pendulum; you only choose when to let go. | One-button Tetris already exists. |

Both are **concepts only** (no code). Want to build one in under 4 KB? PRs welcome.
